# College_Website




A basic **HTML, CSS, and JavaScript** project representing a college homepage with sections for About, Courses, and Contact.

## Features
- Header with navigation bar.
- About section describing the institution.
- Courses section with multiple course cards.
- Contact form with JavaScript validation and alert confirmation.
- Footer with copyright.

## Tech Stack
- **HTML5** for structure
- **CSS3** for styling
- **JavaScript (ES6)** for form handling

## Setup
1. Clone or download the project files.
2. Open `index.html` in any modern browser.
3. Explore the sections and try submitting the contact form.
